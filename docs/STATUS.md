# Implementation status

The controlled Baseline-versus-Proposed experiment contract has completed the final methodological audit and Model-Selection Pre-Study. Qwen3.5 9B Q4_K_M is now the formally selected model for the repeatability gate and, if that gate passes, the main experiment.

Implemented: final 32-task dataset with balanced U2/U3 hidden-constraint rotation and diversified unavailable-evidence constraints; shared browser agent and evidence ledger; capability-matched Baseline/Proposed selection; independent pre-ACT evaluator; durable recording; paired VDA/probe metrics; exact McNemar and paired Wilcoxon reporting; development/repeatability/freeze/main CLI; interrupted-attempt recovery and paired infrastructure reruns; a predeclared lean Baseline-only runner for the Model-Selection Pre-Study, 24-run selected-model repeatability gate, environment capture and summary export.

Current active candidate set for the Model-Selection Pre-Study: Qwen3.5 9B Q4_K_M, Ministral-3 8B Instruct Q4_K_M, Granite 4.1 8B Q4_K_M and Salesforce Llama-xLAM-2 8B FC-R Q4_K_M. Inclusion requires an approximately comparable 8–10B local model, the same Ollama serving stack, Q4_K_M quantization, structured/agentic output suitability and feasibility on the fixed machine. Granite 3.3 8B Instruct Q4_K_M remains the predeclared deployment fallback if Granite 4.1 shows reproducible incompatibility. A candidate may be removed only after the documented fresh-retry deployment rule, never because of poor benchmark performance. The committed runner continues to require Ollama 0.13.3+ as the fixed minimum runtime for this audited protocol.

RNJ-1 8B Instruct Q4_K_M was removed from the active candidate set on 2026-10-02 after reproducible deployment incompatibility on the fixed benchmark machine. Two separate fresh pilots (`device-preflight-v1` and `device-preflight-v2`) both preserved the same pattern: RNJ-1 warm-up failed and `development-02` plus `development-03` terminated as infrastructure failures before probe execution, while Qwen3.5, Ministral-3 and Granite 4.1 had zero infrastructure failures. Ollama server diagnostics showed the RNJ-1 llama-server terminating during model loading with `GGML_ASSERT(hparams.is_swa_any()) failed` and HTTP 500 responses. The exclusion therefore occurred before the full Model-Selection Pre-Study and was based only on reproducible deployment compatibility, not VDA, latency or output quality. The candidate set was subsequently refined after the OLMo feasibility pilot but before any full Model-Selection Pre-Study run: OLMo 3 7B Instruct was replaced by Salesforce Llama-xLAM-2 8B FC-R Q4_K_M. This refinement was motivated by tighter size comparability and stronger task alignment with action selection/function-calling research. Salesforce publishes the official Q4_K_M GGUF and an Ollama-compatible invocation path for xLAM-2. The prior RNJ and OLMo pilot outputs are retained as diagnostic history and are not used as model-selection evidence. The four-model feasibility pilot and full Model-Selection Pre-Study are complete. The next required research step is the 24-run repeatability gate using the selected Qwen3.5 9B Q4_K_M configuration.

Observed engineering evidence: unit tests and browser integration have passed in prior validation, including exact initial U-levels for all 32 tasks and all 64 deterministic demo policy runs. The LEUCO visual language is integrated into the local controlled world with three local kaos design assets, Indonesian copy, responsive layout, exact semantic probe labels, public-only fact visibility and empty/single-item cart states. Demo is engineering evidence, not research data.

Model-selection result: the completed 72-episode Baseline-only pre-study selected Qwen3.5 9B Q4_K_M under the predeclared lexicographic rule. Qwen completed 18/18 healthy runs correctly (VDA 1.00), with zero invalid outputs, zero repairs, zero unrecovered structured failures, and perfect outcome/trajectory repeatability across the six repeated development tasks. Ministral completed 14/18 correctly (VDA 0.778) with four unrecovered structured failures; Granite completed 9/18 correctly (VDA 0.50) with nine unrecovered structured failures; xLAM-2 completed 6/18 correctly (VDA 0.333) with twelve unrecovered structured failures. No candidate had an infrastructure failure in the full pre-study.

Pending research evidence: the 24-run selected-model repeatability gate, formal freeze and 64-run main data collection. Exact probe trajectories remain diagnostic at the gate; stable evaluator outcomes and healthy execution are required.
