# Implementation status

The controlled Baseline-versus-Proposed experiment contract has completed the final methodological audit and is validation-ready for a fresh benchmark machine.

Implemented: final 32-task dataset with balanced U2/U3 hidden-constraint rotation and diversified unavailable-evidence constraints; shared browser agent and evidence ledger; capability-matched Baseline/Proposed selection; independent pre-ACT evaluator; durable recording; paired VDA/probe metrics; exact McNemar and paired Wilcoxon reporting; development/repeatability/freeze/main CLI; interrupted-attempt recovery and paired infrastructure reruns; a predeclared lean Baseline-only Model-Selection Pre-Study runner, 24-run selected-model repeatability gate, environment capture and summary export.

Current Model-Selection Pre-Study candidate set: Qwen3.5 9B Q4_K_M, Ministral-3 8B Instruct Q4_K_M, Granite 4.1 8B Q4_K_M and RNJ-1 8B Instruct Q4_K_M. Inclusion requires an approximately comparable 7–10B local model, the same Ollama serving stack, Q4_K_M quantization, structured/agentic output suitability and feasibility on the fixed machine. Granite 3.3 8B Instruct Q4_K_M is the predeclared deployment fallback if Granite 4.1 shows reproducible incompatibility. A candidate may be removed only after the documented fresh-retry deployment rule, never because of poor benchmark performance. The runner requires Ollama 0.13.3+ because RNJ-1 requires that runtime generation.

Observed engineering evidence: unit tests and browser integration have passed in prior validation, including exact initial U-levels for all 32 tasks and all 64 deterministic demo policy runs. The LEUCO visual language is integrated into the local controlled world with three local kaos design assets, Indonesian copy, responsive layout, exact semantic probe labels, public-only fact visibility and empty/single-item cart states. Demo is engineering evidence, not research data.

Pending research evidence: a fresh pilot on the new final benchmark machine, full Model-Selection Pre-Study, selected-model repeatability gate, formal freeze and main data collection. Older pilot outputs are superseded diagnostic history and must not be reused as research evidence for this audited configuration.
