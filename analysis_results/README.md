# CDEA Analysis Exports

This folder contains the publication tables and summary CSVs recovered from
the supplied master archive.

## Included in this commit
- `tables/Tabel_4_1.csv` through `tables/Tabel_4_6.csv`
- `summary/ringkasan_statistik.csv`

The master archive also contains nine PNG figures and additional detailed
analysis CSVs. Those files are not part of this commit. The figures can be
regenerated by executing `notebooks/main_analysis.ipynb` after restoring the
verified source dataset bundle at the repository root.
